# Закрывающий тег

Адаптивная страница о пути обучения и поиске собственного подхода к вёрстке. Проект выполнен в рамках курса «Фронтенд-разработчик» Яндекс Практикума.

Репозиторий: https://github.com/Dem1Kon/zakrivayuschiy-teg-ad

## Запуск

Откройте файл `index.html` в браузере.

## Технологии

HTML, CSS и JavaScript.
